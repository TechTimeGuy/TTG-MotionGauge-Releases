# TTG MotionGauge

TTG MotionGauge is a Windows desktop application from TechTimeGuy Designs for turning compatible SRT, GPX, and FIT telemetry into customizable gauges, route maps, transparent overlays, and finished videos.

## Public beta

This release is free beta software. It does not require an account, payment, activation, or license key. Beta users should expect that features and file formats may change as testing continues. Pricing for any future stable release has not been decided, and availability of this beta does not promise that all future versions will remain free.

## Downloads

Download installers only from this repository's Releases page or the official TechTimeGuy Designs website. Public installers are Authenticode-signed and accompanied by SHA-256 checksums and a release manifest.

This is intentionally a releases-only repository. Application source, private development history, internal test media, API keys, signing credentials, and customer files are not published here.

## Independence

TTG MotionGauge supports telemetry produced by DJI drones and other compatible devices. TTG MotionGauge is an independent product and is not affiliated with, sponsored by, or endorsed by DJI or MapTiler.

## Optional support

TTG MotionGauge is fully functional without payment. If you would like to support beta development, visit https://techtimeguy.com/motiongauge/support/. Support is a voluntary one-time contribution and does not unlock features or create a software license.
